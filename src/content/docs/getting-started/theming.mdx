## Light and dark

Every color role is a `light-dark()` pair, so a theme follows the `color-scheme` of its element. `tp-theme-switcher` stores the choice and applies it to the document root, which is how the switcher in this site's header themes every demo on the page.

<Preview
  title="Theme switcher variants"
  code={`<tp-theme-switcher></tp-theme-switcher>
<tp-theme-switcher variant="button"></tp-theme-switcher>
<tp-theme-switcher variant="group"></tp-theme-switcher>`}
/>

To avoid a flash of the wrong scheme, apply the stored preference from `<head>`:

<Code code={`<script>
  try {
    const value = localStorage.getItem('tp-theme');
    if (value === 'light' || value === 'dark') {
      document.documentElement.style.colorScheme = value;
      document.documentElement.dataset.theme = value;
    }
  } catch {}
</script>`} />

## Tokens

Components read inherited `--tp-*` custom properties. Override a few roles on any subtree for a brand region, or replace the full set for a new theme.

<Code language="css" code={`.brand-region {
  --tp-primary: oklch(58% 0.22 275deg);
  --tp-primary-foreground: white;
  --tp-ring: oklch(67% 0.18 275deg);
  --tp-radius: 0.75rem;
}`} />

## Motion

Motion has its own token roles: three durations, `--tp-duration-fast` (200ms) for feedback, `--tp-duration-normal` (280ms) for surfaces and layout moves and `--tp-duration-slow` (560ms) for reveals, and three easings, `--tp-easing-standard` for changes within the page, `--tp-easing-enter` for arrivals and `--tp-easing-exit` for departures. Popups and dialogs open on the enter easing and close on the exit easing. Every finite animation is multiplied by `--tp-motion-scale`, which reduced motion sets to `0`. Override the roles on any subtree to retime everything inside it.

<Code language="css" code={`.calm-region {
  --tp-duration-normal: 400ms;
  --tp-easing-enter: cubic-bezier(0.16, 1, 0.3, 1);
}`} />

## Density

Spacing, control heights and icon sizes derive from one seed, `--tp-spacing`, and type from the `--tp-text-*` roles. Every preview on this site has a Default and Compact selector that applies a compact seed to that preview; the choice carries across previews and pages.
