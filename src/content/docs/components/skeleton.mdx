## Usage

A Skeleton has no size or shape attributes: ordinary layout sets its width and height, and a radius token on the host shapes it. It is always hidden from assistive technology, so put `aria-busy` and a label on the region that is loading.

### Motion

<Preview
  title="Pulse, sweep and none"
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-4);max-inline-size:20rem;margin-inline:auto">
  <tp-skeleton style="block-size:var(--tp-space-4)"></tp-skeleton>
  <tp-skeleton motion="sweep" style="block-size:var(--tp-space-4)"></tp-skeleton>
  <tp-skeleton motion="none" style="block-size:var(--tp-space-4)"></tp-skeleton>
</div>`}
/>

`motion` picks the treatment and never changes geometry. Reduced-motion preferences stop either animation; `animated` turns it off for a single placeholder.

Compose placeholders inside the real container so the page does not shift when content arrives.
