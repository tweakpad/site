## Usage

Each item names its target with `href="#id"`; the component never scans the page for headings. It finds the scroll container that holds every target, the document or a Scroll area as here, and marks the innermost target whose region crosses the reading line. Place it in a sticky column inside that same container.

### Navigation

Activating an item scrolls only the content's container and keeps that item current until the reader scrolls again. The default `navigation="fragment"` also records the target in the URL as a history entry, so Back returns to the previous section. Use `navigation="scroll"`, as these examples do, when your application routes on the fragment or the list sits in an embedded panel.

`depth` only indents an item; it is never used for tracking. `label` replaces the default "On this page" title, and a `title` slot accepts richer content. This list follows the article above: scroll it and both lists update.

### Compact

`variant="compact"` draws less attention: one short line per top-level item, with the current one marked. Hovering the lines opens the full list in a card after `open-delay`, and `close-delay` keeps it open briefly after the pointer leaves; the lines are also one Button for keyboard users. `side` is the direction the card grows: `inline-start` for lines on the end edge of the page, `inline-end` for lines on the start edge.

### Reading line

The reading line defaults to the scroll container's `scroll-padding-block-start`, the same CSS you already use to clear a sticky header for anchor links, so a jump always lands on the item it marks. `activation-offset` overrides it with pixels or a percentage. For busy pages, `scroll-throttle` and `scroll-debounce` reduce how often the current item updates.
