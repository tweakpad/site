## Usage

Autocomplete's value is the text itself: picking a suggestion replaces the text, and a form receives whatever is typed. When the value must be one of the items, use Select with `searchable` instead. Supply items as `<option>` children, and label the field with `tp-field` or `label`.

### Matching

<Preview
  title="Prefix matching"
  align="stretch"
  code={`<tp-field label="Country" description="Type the start of each word: un st" style="inline-size:100%;inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" matching="prefix" placeholder="Search countries">
    <option>United Kingdom</option>
    <option>United States</option>
    <option>United Arab Emirates</option>
    <option>South Africa</option>
    <option>South Korea</option>
    <option>New Zealand</option>
  </tp-autocomplete>
</tp-field>`}
/>

The default `fuzzy` matching ranks results by relevance and tolerates typos, so "rasberry" still finds Raspberry. `prefix`, `contains` and `exact` keep the items in their given order and suit codes, names and lists where a typo match would be noise. Matched text is highlighted in every mode.

`<optgroup>` labels sections of suggestions. `show-trigger` adds a button that opens the full list, and `open-on-input-click` opens it on click, which helps when people browse rather than type.

### Completion

<Preview
  title="Inline completion"
  align="stretch"
  code={`<tp-field label="Assign to" style="inline-size:100%;inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" completion-mode="both" auto-highlight show-clear placeholder="Teammate name">
    <option>Amara Okafor</option>
    <option>Daniel Kim</option>
    <option>Lucía Fernández</option>
    <option>Maya Chen</option>
    <option>Noah Williams</option>
  </tp-autocomplete>
</tp-field>`}
/>

`completion-mode="both"` fills in the highlighted suggestion as you type, selecting the completed part so typing continues naturally. `auto-highlight` highlights the first suggestion, so Enter accepts it. `show-clear` adds a clear button.

### Keywords

<Preview
  title="Searching hidden fields"
  align="stretch"
  code={`<tp-field label="Command" description="Try: invoice, teammate, dark" style="inline-size:100%;inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" id="autocomplete-commands" placeholder="Search commands"></tp-autocomplete>
</tp-field>`}
  script={`const commands = [
  { value: 'Create invoice', keywords: ['bill', 'billing', 'payment'] },
  { value: 'Invite member', keywords: ['teammate', 'user', 'people'] },
  { value: 'Change theme', keywords: ['dark', 'light', 'appearance'] },
  { value: 'Export data', keywords: ['csv', 'download', 'backup'] },
];
await customElements.whenDefined('tp-autocomplete');
const autocomplete = document.querySelector('#autocomplete-commands');
autocomplete.items = commands.map(({ value }) => value);
autocomplete.matchFields = (item) => commands.find((command) => command.value === item)?.keywords ?? [];`}
/>

The `items` property accepts strings, records and groups when the list comes from data. `matchFields` adds searchable text that is never displayed, such as aliases or keywords. Results can also come from a server through the `source` property.

### Forms

<Preview
  title="In a form"
  align="stretch"
  code={`<form style="display:grid;gap:var(--tp-space-4);inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-field label="Job title">
    <tp-autocomplete style="inline-size:100%" name="title" required placeholder="e.g. Product designer">
      <option>Product designer</option>
      <option>Product manager</option>
      <option>Frontend engineer</option>
      <option>Data analyst</option>
    </tp-autocomplete>
  </tp-field>
  <tp-button type="submit" style="justify-self:start">Save profile</tp-button>
</form>`}
/>

With `name`, the form receives the text, including text that matches no suggestion. `required` requires text. Enter with nothing highlighted submits the form, and Escape first closes the suggestions, then clears the text.
