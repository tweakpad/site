## Usage

The group owns the outside border and the focus and invalid ring; the editor inside keeps its native editing, validation and form value. Put exactly one `tp-input`, `tp-text-area` or native editor in the default slot, and label it with a Field as usual.

### Addons

`inline-start` and `inline-end` hold text or icons beside the editor. Clicking a non-interactive addon focuses the editor, so units and prefixes behave like part of the field.

### Actions

Buttons in the `action` slot sit after the editor and stay independently operable, even when the editor is read-only or disabled. `action-variant` and `action-size` set their defaults; an explicitly configured Button wins.

<Preview
  title="Actions"
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-4);max-inline-size:24rem;margin-inline:auto;inline-size:100%">
  <tp-field label="Invite link">
    <tp-input-group>
      <tp-input id="input-group-copy-input" readonly default-value="https://tweakpad.app/join/8f2c41"></tp-input>
      <tp-button id="input-group-copy" slot="action">Copy</tp-button>
    </tp-input-group>
  </tp-field>
  <tp-field label="Coupon code" description="Codes are case-insensitive.">
    <tp-input-group action-variant="secondary">
      <tp-input placeholder="SPRING25"></tp-input>
      <tp-button slot="action">Apply</tp-button>
    </tp-input-group>
  </tp-field>
</div>`}
  script={`const button = document.querySelector('#input-group-copy');
button.addEventListener('click', async () => {
  try {
    await navigator.clipboard.writeText(document.querySelector('#input-group-copy-input').value);
    button.textContent = 'Copied';
  } catch {
    button.textContent = 'Select to copy';
  }
  setTimeout(() => (button.textContent = 'Copy'), 1600);
});`}
/>

### Menus and tooltips in addons

Addon slots also take interactive components, such as a Menu that picks a country code or a Tooltip that explains the expected format. They keep their own focus and keyboard behavior; give an icon-only trigger an `aria-label`.

### Block edges

`block-start` and `block-end` span the group above and below the editor. With a Text area they make a composer: a context line on top, a character count and submit actions in the footer.

<Preview
  title="Composer"
  align="stretch"
  code={`<tp-field label="Reply" style="max-inline-size:30rem;margin-inline:auto;inline-size:100%">
  <tp-input-group>
    <span slot="block-start">Replying to Jonas Weber</span>
    <tp-text-area id="input-group-reply" maxlength="280" placeholder="Share an update with the team"></tp-text-area>
    <span id="input-group-count" slot="block-end" style="margin-inline-end:auto">0/280</span>
    <tp-button slot="block-end" variant="ghost" size="sm">Cancel</tp-button>
    <tp-button slot="block-end" size="sm">Post reply</tp-button>
  </tp-input-group>
</tp-field>`}
  script={`const reply = document.querySelector('#input-group-reply');
reply.addEventListener('input', () => {
  document.querySelector('#input-group-count').textContent = reply.value.length + '/280';
});`}
/>
