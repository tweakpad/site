## Usage

A Marker annotates a stream, such as a chat transcript or an activity log, without becoming a message itself. It adds no role, so meaning lives in its text; supply `role="status"` yourself when the content is a live update.

### Variants

The default has no boundary. `separator` centres the content between two rules, for breaks in a timeline; `border` sets it above a rule, for a step that closes a section.

### Icons

The `icon` slot takes an Icon or a decorative Spinner. The icon region is hidden from assistive technology, so the text must carry the meaning on its own.

### Shimmer

`shimmer` sweeps a highlight across the text while a status is still streaming, such as an agent step in progress. Remove it when the step finishes; reduced motion shows the text without the sweep. `--tp-shimmer-color`, `--tp-shimmer-duration`, `--tp-shimmer-spread` and `--tp-shimmer-angle` tune it.

### Actions

A Marker owns no action state, but its content can hold a link or a Button. The control keeps its own focus and semantics.

  title="With an action"

  <tp-marker variant="separator"><tp-button variant="outline" size="sm">Review 3 changes</tp-button></tp-marker>
</div>`}
