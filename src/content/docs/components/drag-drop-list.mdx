## Usage

Items are plain data, so the list is fed from script: set `defaultValue` (uncontrolled) or `value` (controlled) before the first render, with each item's `id` and `label`. Each drag hovers a preview order; a drop commits a new array, and Escape or a drop outside restores the committed order.

### Keyboard

Every row has a named handle Button. Focus it, press Space or Enter to pick the item up, move it with the arrow keys, and press Space or Enter again to drop it; Escape cancels. A live region announces each step.

### Reading the value

`tp-value-change` fires with each proposed order and can be cancelled; `tp-value-commit` fires once the drop has settled. Read `value` then to save the order.

### Variants and sizes

`variant` is `ghost` (the default, rows without a boundary), `outline` or `subdued`. `size` steps the rows down from `default` through `sm` to `xs` for side panels and settings popovers.

### Activation and swapping

By default only the handle starts a pointer drag, which keeps text in the row selectable. `activation="item"` lets the whole row start one, after a short delay or movement so clicks still work. `reorder-mode="swap"` exchanges two items instead of shifting the ones between them. The `feedback` property picks the drag feedback; `'clone'`, used here, leaves a copy in the row's layout position while the item moves.

### Rich rows

`renderItem` returns the content of each row from its item and a context, so rows can carry Badges and their own actions; a control in the `actions` slot stays separately operable. The context's `preview` flag marks the copy shown while dragging. `renderOverlay` draws the row that follows the pointer.

<Preview
  title="Custom rows and overlay"
  align="stretch"
  code={`<div id="drag-drop-list-rich" style="display:grid;gap:var(--tp-space-3);max-inline-size:30rem;margin-inline:auto;inline-size:100%">
  <output id="drag-drop-list-rich-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Drag to reorder, or open a release.</output>
</div>`}
  script={`import { html } from 'lit';

// Configure the list before it first renders, then mount it.
const list = document.createElement('tp-drag-drop-list');
list.label = 'Release queue';
list.variant = 'outline';
const output = document.querySelector('#drag-drop-list-rich-output');
const tone = { Ready: 'success', 'In review': 'secondary', Blocked: 'destructive' };
list.renderItem = (item, context) => html\`<span>\${item.label} <tp-badge variant=\${tone[item.status]}>\${item.status}</tp-badge></span>
  <tp-button slot="actions" size="sm" variant="outline" .disabled=\${context.preview}
    @click=\${() => (output.textContent = 'Opened ' + item.label)}>Open</tp-button>\`;
list.renderOverlay = (item) => html\`<tp-list-item variant="outline">\${item.label}
  <tp-badge slot="actions" variant="outline">Moving</tp-badge></tp-list-item>\`;
list.defaultValue = [
  { id: 'v2-4', label: 'v2.4 Billing', status: 'Ready' },
  { id: 'v2-5', label: 'v2.5 Audit log', status: 'In review' },
  { id: 'v2-6', label: 'v2.6 SSO groups', status: 'Blocked' },
];
document.querySelector('#drag-drop-list-rich').prepend(list);`}
/>

### Disabled and read-only

`disabled` and `readonly` stop reordering and cancel a drag in progress, while leaving the rows readable. Use `readonly` when the order is visible but locked, such as while a save is pending.

### Connected lists

Lists that share one `DragDropManager` from `@tweakpad/ui/drag-drop`, each with a unique `group`, can pass items between them, such as columns on a board. `moveItem()` performs the same atomic move from code, for example from a "Move to Ready" menu action.
