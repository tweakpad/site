## Usage

A Message lays out one row: avatar column, header, content and footer. It does not send anything or infer delivery state; the visible surface is a `tp-bubble`, and status text in the footer comes from your application.

### Alignment

`align="end"` marks the current sender and `align="start"` everyone else. Avatar and footer follow the logical side, including right-to-left; set the nested Bubble's `align` to match.

<Preview
  title="Sender sides"
  align="stretch"
  code={`<div style="display:flex;flex-direction:column;gap:var(--tp-space-6);max-inline-size:26rem;margin-inline:auto">
  <tp-message aria-label="Priya Shah">
    <tp-avatar slot="avatar" fallback="PS" alt="Priya Shah"></tp-avatar>
    <tp-bubble>The staging deploy failed on the migration step.</tp-bubble>
  </tp-message>
  <tp-message align="end" aria-label="You">
    <tp-avatar slot="avatar" fallback="JL" alt="Jordan Lee"></tp-avatar>
    <tp-bubble align="end" variant="default">Rolling it back now. I'll post the logs in a minute.</tp-bubble>
  </tp-message>
</div>`}
/>

Alignment alone does not identify a sender. Give every row an accessible name through `aria-label`, the avatar's `alt` or a header.

### Header and footer

`author` and `timestamp` fill the default header; the time is rendered by Time, so it formats for the reader's locale. The `footer` slot carries delivery status, read receipts or reactions, and empty regions take no space.

<Preview
  title="Header and footer"
  align="stretch"
  code={`<div style="display:flex;flex-direction:column;gap:var(--tp-space-6);max-inline-size:26rem;margin-inline:auto">
  <tp-message author="Sam Rivera" timestamp="2026-10-09T14:32:00">
    <tp-bubble>The Q3 invoice export is attached to the ticket.</tp-bubble>
  </tp-message>
  <tp-message align="end" author="You" timestamp="2026-10-09T14:35:00">
    <tp-bubble align="end" variant="default">Thanks, forwarding it to finance.</tp-bubble>
    <span slot="footer">Read by Sam</span>
  </tp-message>
</div>`}
/>

### Group

`tp-message-group` stacks consecutive messages from one sender with tighter spacing. An empty avatar slot keeps the column on earlier rows so the bubbles line up under the final avatar.

<Preview
  title="Message group"
  align="stretch"
  code={`<tp-message-group style="max-inline-size:26rem;margin-inline:auto">
  <tp-message aria-label="Sam Rivera">
    <span slot="avatar" aria-hidden="true"></span>
    <tp-bubble>I checked the release checklist.</tp-bubble>
  </tp-message>
  <tp-message aria-label="Sam Rivera">
    <tp-avatar slot="avatar" fallback="SR" alt="Sam Rivera"></tp-avatar>
    <tp-bubble>The remaining items are assigned to the platform team.</tp-bubble>
  </tp-message>
</tp-message-group>`}
/>

### Actions

Actions are ordinary named controls in the footer: a Button for one-off commands, Toggles for feedback that has a pressed state. Each stays its own tab stop.

### Attachments

Put files and images in `tp-attachment` next to the Bubble; the Message's content area owns the spacing between them.
