## How it's composed

- **Progress** bars each carry the file name as their label, so every bar is announced with what it measures.
- **Badge** summarizes the batch in the Card's `action` slot.
- **Button** keeps cancel and hide as quiet secondary actions; there is no primary action while files are uploading.

## Make it yours

Replace a finished bar with a List row and an open action, and show an error state with a retry for failed files. To let people pick or drop the files too, File upload's upload adapter reports the same per-file progress, retry and cancellation.
