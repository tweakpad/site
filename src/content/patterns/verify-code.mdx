## How it's composed

- **One-time code field** handles paste, autofill from the operating system and moving between cells; `group-lengths` splits the six digits into two groups of three, which is easier to read back.
- **Field** names the code for assistive technology; the visible cells stay unlabeled.
- **Button** puts the secondary resend before the primary verify, in reading order.

## Make it yours

Submit automatically when the last digit is entered, and start a cooldown on the resend action after it is used.
