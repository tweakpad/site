## How it's composed

- **Card** keeps the same frame as [Sign in](../sign-in), so moving between the two screens feels like one flow.
- **Field** carries a description for the link's expiry, which screen readers announce with the input.
- **Button** pairs a ghost link back to sign in with the primary submit in the footer, in reading order.

## Make it yours

After a successful request, replace the form with a confirmation message and a resend action, and keep the response identical whether or not the address has an account.
