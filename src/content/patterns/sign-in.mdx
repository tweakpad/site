## How it's composed

- **Card** frames the form. The heading and description go in its `header` and `description` slots; the primary action sits in `footer`, so it lines up with every other card in your product.
- **Field** owns each label and error. The Inputs keep their native `type` and `autocomplete`, which is what password managers look for.
- **Checkbox** in a horizontal Field puts the label beside the control and makes the whole label clickable.
- **Button** with `variant="link"` and `href` is a real anchor for the recovery route, so it opens in a new tab and shows its URL like any link.

## Make it yours

Replace the form's submit handling with your own, add a social sign-in row above the fields with outline Buttons, or swap the password for a one-time code with the [Verify code](../verify-code) pattern.
